## 폰트
- 본문(한글): Pretendard Variable
- 영문(라틴 글자·숫자·기호): **설립체 유건욱** — `ArcLatin` `@font-face`(unicode-range)로 라틴 글자·숫자만 적용, 한글은 Pretendard 유지 (두 번째 섹션은 강조어 "디지털 코어"만 설립체, 나머지 글자·알약 라벨은 Pretendard)
- 두 번째 섹션 문장: **설립체 유건욱** — 눈누 CDN(`establishRetrosansOTF.woff`)에서 `@font-face`로 로드. 폰트 파일은 저장소에 포함하지 않음(재배포 금지 라이선스)

## 스크롤 인트로 (`js/main.js`, 장면 높이 600vh / sticky 100vh)
1. 정육각형 3개 — 스크롤하면 이미지가 나타남 (호버 이벤트 없음)
2. 가운데 육각형이 `clip-path` 창으로 커지며 뒤 배경이 드러남
3. 배경이 엘리베이터처럼 위로 올라가며 아래 검정 그라데이션이 드러남
4. 검은 배경에서 문장이 글자 단위로 하나씩 날아옴 (스크롤 연동, 역방향 재생 가능)
- `prefers-reduced-motion` 이면 정적 레이아웃으로 표시
- 이미지 교체 시 `.hex__img`(3개)와 `.reveal__img`(1개)에 같은 이미지를 넣을 것

- 장면 700vh: 엘리베이터 상승 후 빈 화면 → 육각형이 중앙에서 커짐 → 글자 날아옴

## 히어로 영상
- `assets/video/hero.mp4` (1280×720, 10초, H.264 CRF28, 약 1.7MB) — 원본 1920×1080 19MB(`assets/images/tc09880000023.mp4`, 저장소 제외)를 압축
- 가운데 육각형이 커지며 드러나는 **배경 레이어(.reveal)** 가 이 영상이며, 무한 반복 재생. 육각형 창이 커지는 동안·엘리베이터로 올라가기 전까지만 재생하고 화면에서 사라지면 정지
- 양옆 육각형(code, cloud)은 같은 영상 프레임을 `<canvas>`에 육각형 위치만큼 잘라 그려서 창문처럼 비쳐 보임 (가운데·전체 배경과 선이 이어짐, 영상 디코딩은 1개). 양옆이 밀려나 사라지면 그리기 중단

## Principles 중앙 SVG (나선형 육각형 패턴)
- `assets/spiral.svg` (약 220KB, 2048×2048 viewBox) — 참고 이미지 위에서 **직선 405개를 검출해 깨끗한 `<line>`으로 다시 그림**(Hough 변환 후 같은 직선끼리 병합). 흰 라인은 래스터 추적이 아니라 순수 직선이라 끊김·잔상이 없음
- 면(어두운 회색 그라데이션)은 회색 6단계를 벡터로 추적해 라인 아래에 깖
- 스크롤 연출(JS): 각 라인에 `pathLength=1`·`stroke-dashoffset`을 걸어 **가장 바깥 라인부터, 바깥 끝에서 안쪽으로 한 줄씩 그려짐**. 면은 방사형 마스크로 같은 방향으로 번지며 채워짐. 섹션이 화면에 들어올 때 시작해 섹션 끝(마지막 카드가 지나갈 때)에서 완성, 이징 없이 선형
- JS가 꺼져 있거나 `fetch`가 실패하면 `<img>`로 완성된 정적 SVG를 표시
